# Sequence Cutout Studio 用户使用指南

适用版本：0.4.0-internal.1

---

## 1. 快速开始

1. 解压绿色包。
2. 双击顶层的 `SequenceCutoutStudio-Internal.exe`。
3. 等待进入主界面。
4. 确认左侧环境自检通过。
5. 选择视频或 PNG 序列帧文件夹。
6. 如果选择的是视频，先切成序列帧。
7. 先做一次单帧测试。
8. 确认效果可接受后，再批量处理。
9. 在预览检查里查看原图、Raw 和 Soft。
10. 质量验收提示疑似问题时，点击对应帧复核。
11. 导出透明 PNG 序列。

---

## 2. 导入素材

支持两种输入：

```text
视频文件：MP4 / MOV / WEBM / MKV
PNG 序列帧文件夹
```

如果导入视频，需要设置：

```text
FPS：每秒切多少帧
时长秒数：0 表示尽量切完整段视频
输出前缀：切出来的 PNG 文件名前缀
```

如果导入 PNG 序列帧文件夹，软件会扫描文件数量、尺寸和首尾帧。

建议素材放在普通本地路径下，例如：

```text
D:\cutout-test\sample
```

路径可以包含中文，但正式交付素材建议避免过长路径。

---

## 3. 单帧测试

单帧测试用于先看效果，不要一开始就直接跑完整批量。

推荐流程：

```text
1. 导入素材
2. 点击“测试单帧”
3. 查看 Raw 初步结果
4. 查看 Soft 修边结果
5. 根据效果决定是否批量处理
```

Raw 表示自动去背景后的初步结果。  
Soft 表示经过修边后的结果。

如果 Raw 阶段已经把主体扣掉，修边通常无法把主体补回来。

---

## 4. 批量处理

确认单帧测试基本可用后，再点击“批量处理”。

批量处理会生成：

```text
Raw 目录：自动去背景初步结果
Soft 目录：修边后的透明 PNG
```

处理完成后，软件会检查：

```text
输入帧数量
Raw 数量
Soft 数量
疑似问题帧
```

如果质量验收提示疑似问题，请点击问题帧复核，不建议直接交付。

---

## 5. 预览检查

预览检查用于判断结果是否可用。

可切换：

```text
原图
Raw
Soft
对比
```

可切换背景：

```text
棋盘格
黑底
白底
灰底
自定义背景图
```

建议检查：

```text
黑底：看白边、浅色残留
白底：看黑边、深色残留
灰底：看普通边缘是否自然
棋盘格：看透明区域是否完整
自定义背景图：看放入项目背景后的效果
```

如果是动画序列，建议播放检查是否闪烁。

---

## 6. 质量验收

质量验收用于提示这一批序列里可能需要人工复核的帧。

它会告诉你：

```text
输出帧数是否完整
是否发现疑似问题
哪些帧建议检查
```

点击疑似问题帧后，工作区会跳到预览检查，方便直接查看该帧。

质量验收不是最终判定，它是辅助检查工具。最终是否可交付，仍需要人工看图确认。

---

## 7. 导出透明 PNG 序列

批量处理完成后，可以导出透明 PNG 序列。

可设置：

```text
导出命名
起始编号
补零位数
```

示例：

```text
导出命名：attack
起始编号：1
补零位数：4
```

输出文件：

```text
attack_0001.png
attack_0002.png
attack_0003.png
```

软件会在结果旁自动创建 exports 文件夹，并生成 manifest.json 记录导出映射。

---

## 8. 常见问题

### 环境自检失败

请确认使用的是完整绿色包，并从顶层 `SequenceCutoutStudio-Internal.exe` 启动。

### 批量处理失败

先看处理日志。常见原因包括：

```text
输入为空
素材目录不可读
自动去背景失败
修边失败
输出数量不一致
```

### 质量验收提示疑似问题

这不一定代表整批不可用，但必须检查对应帧。常见原因包括主体局部被扣掉、闪烁、边缘变化过大。

### 导出失败

请检查：

```text
Soft 结果是否已经生成
目标磁盘空间是否足够
导出路径是否过长
目录是否有写入权限
```

---

## 9. 推荐使用习惯

```text
先单帧测试，再批量处理。
先看 Raw，再看 Soft。
发现疑似问题帧时，不要只看第一帧。
导出前确认 Soft 结果数量完整。
复杂素材先小批量试，不要直接大批量交付。
```
