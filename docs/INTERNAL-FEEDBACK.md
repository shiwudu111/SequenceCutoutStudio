# Sequence Cutout Studio 内测反馈模板

反馈问题时，请优先填写版本号。版本号显示在软件界面中，zip 文件名里也包含版本号。

---

## 1. 基本信息

```text
软件版本：
zip 文件名：
电脑系统：
是否为干净电脑：
```

示例：

```text
软件版本：0.4.0-internal.1
zip 文件名：SequenceCutoutStudio-Internal-v0.4.0-internal.1-win-x64.zip
电脑系统：Windows 11
是否为干净电脑：是
```
