# Sequence Cutout Studio 正式上线执行路线图

日期：2026-06-12  
目标版本：正式上线候选版  
当前基线：0.4.0-internal.1 已完成内测绿色包交付，Phase 6A 已完成第一轮去背景质量报告。

---

## 1. 总目标

把 Sequence Cutout Studio 从“内测可用工具”推进到“用户可以稳定拿来处理素材的正式产品”。

正式上线前最低标准：

```text
1. 主流程稳定：导入、切帧、去背景、修边、预览、导出不崩。
2. UI 布局固定：后续功能只扩展已有面板，不新增主流程窗口。
3. 结果可验收：用户能快速判断这一批结果是否可用。
4. 问题可定位：软件能标出疑似问题帧，而不是让用户逐帧翻。
5. 质量边界清楚：普通素材可用，困难素材有明确处理策略。
6. 发布包稳定：绿色包、launcher、portable Python 链路不破。
```

---

## 2. 防目标漂移规则

后续每个阶段开始前必须先确认：

```text
1. 本阶段唯一主目标是什么
2. 本阶段不做什么
3. 是否会影响 launcher / portable Python / rembg / postprocess 链路
4. 是否需要重新打绿色包
5. 验收命令是什么
6. 完成后是否更新 docs/ITERATION_BASELINE.md
```

后续功能扩展必须遵守：

```text
不新增主流程窗口。
不新增临时主区域。
不把 debug 信息暴露到普通用户主流程。
不恢复 .venv。
不调用 rembg.exe。
不绕开 tools/python/python.exe + tools/rembg_runner.py 链路。
不提交 portable-root / release / dist / zip。
```
