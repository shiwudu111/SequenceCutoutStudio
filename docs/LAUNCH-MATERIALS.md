# Phase 6G 发布物料准备

适用版本：0.4.0-internal.1

---

## 1. 发布物料目标

正式上线物料只展示当前版本已经稳定的能力，不夸大边界素材。

主信息：

```text
Sequence Cutout Studio 是一款面向游戏美术的本地序列帧透明化处理工具。
它可以把视频或 PNG 序列帧处理成透明 PNG 序列，并提供 Raw / Soft 预览、质量验收和疑似问题帧复核。
```

---

## 2. 推荐截图 / 动图

建议准备 4 组截图或短动图：

| 编号 | 内容 | 目的 |
| --- | --- | --- |
| A1 | 主界面三栏布局 | 展示完整工作台 |
| A2 | 简单背景或绿色背景处理前后 | 展示稳定去背景效果 |
| A3 | Raw / Soft / 黑白灰背景预览 | 展示验收能力 |
| A4 | 质量验收疑似问题帧跳转 | 展示问题定位能力 |

推荐样本：

```text
02绿色背景_12fps_4s
04简单背景_12fps_4s
14遮挡旋转_12fps_4s
```

这些样本更接近 A / A-，适合做正式宣传第一屏。

---

## 3. 不建议作为宣传主图的样本

不建议把下面样本作为宣传主图或“稳定能力”案例：

```text
07低明度低对比背景
08高明度低对比背景
09毛发测试
10发光法术
12透明布料
06复杂室外背景
```

这些样本可以用于“能力边界”或“质量验收如何发现问题”的说明，但不适合作为首屏宣传效果。

---

## 4. 推荐宣传文案

短版：

```text
本地运行的游戏序列帧透明化工具。支持视频切帧、批量自动去背景、Raw / Soft 预览、质量验收和透明 PNG 序列导出。
```

长版：

```text
Sequence Cutout Studio 面向游戏美术和动画素材处理流程，帮助用户把视频或 PNG 序列帧批量处理成透明 PNG。软件在本地运行，支持单帧测试、批量处理、Raw / Soft 对比预览、黑白灰与棋盘格验收背景、疑似问题帧提示，以及按命名规则导出 PNG 序列。
```

---

## 5. 发布说明中的边界文案

建议直接写清楚：

```text
当前版本更适合主体明确、背景相对简单、主体与背景区分明显的素材。
低对比、毛发、半透明、复杂光效和复杂背景仍需要人工检查，不建议承诺完全自动。
```

这样可以减少用户拿最困难素材直接评价软件“不可用”的落差。

---

## 6. 发布前截图清单

发布前至少确认：

```text
[ ] 主界面截图中左侧阶段显示正确
[ ] 截图里没有开发路径、报错、乱码
[ ] 预览图不要使用 C / D 级边界素材作为正向案例
[ ] 质量验收截图可以展示“发现疑似问题帧”，但不要让用户误解为自动修复
[ ] 导出目录截图中 PNG 命名清晰
[ ] 文案不承诺 Sprite Sheet / plist / TexturePacker JSON
```
