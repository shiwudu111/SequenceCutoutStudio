# Sequence Cutout Studio UI 布局与功能承载规则

日期：2026-06-12  
阶段：Phase 6B  
目标：固定正式上线前的主界面布局，防止后续功能继续以新增窗口或临时区域的方式扩张。

---

## 1. 总原则

正式上线前，主界面采用固定工作台结构。

```text
左侧：全局流程、阶段状态、环境自检、批处理状态
主工作区：输入、处理、导出、预览、质量验收、日志
```

后续功能必须进入既有面板，不新增主流程窗口。

允许的窗口：

```text
[x] 系统文件选择窗口
[x] 系统文件夹选择窗口
[x] 必要确认弹窗
[x] 错误详情弹窗
[x] 当前已有预览大图 lightbox
```

禁止的扩张方式：

```text
[ ] 新增独立功能窗口
[ ] 新增悬浮工具箱
[ ] 新增主流程临时面板
[ ] 把 debug 信息放到普通用户主流程
[ ] 为单一功能临时打破主界面网格
```

---

## 2. 固定面板

主工作区固定为六个面板。

| 面板 | className | 职责 |
| --- | --- | --- |
| 输入素材 | `input-panel` | 选择视频、选择序列帧、拖入素材、视频切帧、素材基础信息 |
| 处理参数 | `process-panel` | 单帧测试、批量处理、只重跑边缘、修边预设、参数保存/读取 |
| 导出设置 | `export-panel` | 输出目录、导出 PNG 序列、命名前缀、起始编号、补零位数 |
| 预览检查 | `preview-panel` | Original / Raw / Soft / Compare 预览、背景切换、播放、帧导航 |
| 质量验收 | `quality-panel` | 数量一致性、alpha 波动、疑似问题帧、问题帧跳转 |
| 处理日志 | `log-panel` | 用户可读日志、失败详情入口、debug 信息入口 |

## 4. 布局断点

桌面优先，不做移动端适配。

```text
宽屏：三列工作台
标准屏：两列工作台
窄屏：单列堆叠，允许纵向滚动
```

最低验收分辨率：

```text
1366 x 768：可完成主流程，不遮挡关键按钮
1600 x 900：主要工作流舒适
1920 x 1080：信息完整，预览区优先
```

---

## 5. 信息层级

普通用户主流程只显示一级和二级信息。

```text
一级信息：下一步要做什么
二级信息：当前结果是否正常
三级信息：技术细节、debug、路径、异常堆栈
```

三级信息只能进入：

```text
处理日志
详情折叠区
错误详情弹窗
开发文档
```

## 6. Phase 6B 完成边界

本阶段只固定布局和功能承载边界。

本阶段不做：

```text
[ ] 不实现问题帧检测
[ ] 不实现 alpha 波动算法
[ ] 不接入新模型
[ ] 不改 rembg / postprocess / portable Python 链路
[ ] 不重新设计启动器
[ ] 不新增主流程窗口
```

完成后，下一阶段 Phase 6C 的质量验收能力必须落在 `quality-panel` 内。
