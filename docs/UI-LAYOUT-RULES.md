# Sequence Cutout Studio UI 布局与功能承载规则

日期：2026-06-12  
阶段：Phase 6B 已收口
目标：固定正式上线前的主界面布局，防止后续功能继续以新增窗口或临时区域的方式扩张。

---

## 1. 总原则

正式上线前，主界面采用固定工作台结构。

```text
左侧：真实流程导航、阶段状态、环境自检、批处理状态
主工作区：输入、处理、导出、预览、质量验收、日志
```

后续功能必须进入既有面板，不新增主流程窗口。

左侧流程项必须是真实导航，不允许做成“看起来可点击但没有功能”的伪按钮。

```text
导入素材：定位到输入素材面板
视频切帧：定位到视频切帧区域
AI 抠图：定位到处理参数面板
边缘处理：定位到边缘参数区域
预览导出：定位到预览 / 导出工作区
```

点击流程项时，对应流程项和目标区域必须有蓝色高亮；如果目标区域不在当前可见范围内，应自动滚动到目标区域。

允许的窗口：

```text
[x] 系统文件选择窗口
[x] 系统文件夹选择窗口
[x] 必要确认弹窗
[x] 错误详情弹窗
[x] 当前已有预览大图 lightbox
```

禁止的扩张方式：

```text
[ ] 新增独立功能窗口
[ ] 新增悬浮工具箱
[ ] 新增主流程临时面板
[ ] 把 debug 信息放到普通用户主流程
[ ] 为单一功能临时打破主界面网格
```

---

## 2. 固定面板

主工作区固定为六个面板。

| 面板 | className | 职责 |
| --- | --- | --- |
| 输入素材 | `input-panel` | 选择视频、选择序列帧、拖入素材、视频切帧、素材基础信息 |
| 处理参数 | `process-panel` | 单帧测试、批量处理、只重跑边缘、修边预设、参数保存/读取 |
| 导出设置 | `export-panel` | 输出目录、导出 PNG 序列、命名前缀、起始编号、补零位数 |
| 预览检查 | `preview-panel` | Original / Raw / Soft / Compare 预览、背景切换、播放、帧导航 |
| 质量验收 | `quality-panel` | 数量一致性、alpha 波动、疑似问题帧、问题帧跳转 |
| 处理日志 | `log-panel` | 用户可读日志、失败详情入口、debug 信息入口 |

## 4. 布局断点

桌面优先，不做移动端适配。

```text
宽屏：三列工作台。左栏输入，中栏处理 / 导出 / 质量验收，右栏预览 / 日志。
标准屏：两列工作台。预览放右栏上方，日志在右栏预览下方露出明确面积。
窄屏：单列堆叠，顺序为输入、预览、处理、导出、质量验收、日志，允许纵向滚动。
```

最低验收分辨率：

```text
1366 x 768：可完成主流程，不遮挡关键按钮
1600 x 900：主要工作流舒适
1920 x 1080：信息完整，预览区优先
```

日志是主流程判断工具，不是象征性附属区。

```text
第一屏必须露出处理日志栏。
日志栏至少有明确可读面积，不能只露标题或极小窗口。
日志显示完整日志流，不只显示最近几条。
日志内部可以滚动，但日志面板自身不能过矮。
宽屏下日志放右栏预览下方；双栏 / 单栏下日志排在预览和处理区后方，可通过页面滚动查看完整日志。
```

三栏断点不能为了修复普通窗口拥挤而粗暴上调。
Phase 6B 已固定：宽度 1336px 及以上保持三栏工作台；1335px 及以下才允许进入双栏；窄屏再进入单栏。
后续优化二栏 / 单栏时，不允许反复改动已经确认的三栏断点。
三栏状态已按人工验收冻结：除非出现阻断级 bug，后续不再调整三栏视觉细节、三栏断点、三栏面板顺序和三栏预览区高度策略。
二栏状态已按人工验收冻结：右栏必须保持“预览检查在上、处理参数紧接其下”，左栏输入素材保持三栏输入方案，不再回退为 DOM 自动排版或把处理参数顶出第一屏。
单栏状态已按人工验收冻结：顺序必须保持“输入素材、预览检查、处理参数、导出设置、质量验收、处理日志”；输入区纵向空间保持克制，预览区使用 4:3，不再回退为过长比例。

## 5. 信息层级

普通用户主流程只显示一级和二级信息。

```text
一级信息：下一步要做什么
二级信息：当前结果是否正常
三级信息：技术细节、debug、路径、异常堆栈
```

三级信息只能进入：

```text
处理日志
详情折叠区
错误详情弹窗
开发文档
```
