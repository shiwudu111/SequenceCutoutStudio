## 主要能力

```text
视频导入与序列帧切分
PNG 序列帧文件夹导入
单帧自动去背景测试
批量自动去背景
Raw 初步结果与 Soft 修边结果预览
黑底 / 白底 / 灰底 / 棋盘格 / 自定义背景验收
质量验收与疑似问题帧提示
点击疑似问题帧跳转预览检查
透明 PNG 序列导出
导出命名规则：前缀、起始编号、补零位数
导出 manifest.json 清单
绿色包 + 顶层启动器
```

## 稳定性改进

```text
修复绿色包运行时依赖问题，改为 portable Python 链路
移除旧 .venv 运行方式
增加真实环境自检
增加 launcher 启动页
补强导出目录读写检查
增加导出磁盘空间检查
避免重复导出覆盖已有目录
增加长路径提前提示
保留 export.log 方便定位问题
失败提示更偏用户语言，技术细节保留在日志中
```

---

## UI 与验收改进

```text
固定三栏、二栏、单栏布局规则
左侧流程导航可定位到对应面板
预览检查、处理参数、导出设置、质量验收、处理日志各有固定承载位置
质量验收主界面只展示用户需要的信息：是否有问题、哪些帧有问题
隐藏不必要的技术指标，避免干扰普通使用流程
```

---

## 已知限制

```text
低对比素材可能误删主体
毛发、绒毛、羽毛等细碎边缘仍不稳定
半透明布料、玻璃、烟雾等不作为当前版本稳定承诺
复杂发光和魔法光效需要人工检查
复杂背景可能残留或误删
强运动模糊和快速旋转可能出现帧间闪烁
```

---

安装器
自动更新
账号系统
云端处理
任务队列取消
Sprite Sheet 导出
