# 序列预览优化验证记录

日期：2026-09-09。状态：开发验证及用户复测通过，本轮预览优化已归档；尚未重新发布绿色包。

## 完成内容

| 需求 | 实现与验证 |
| --- | --- |
| GIF 选择与原始拆帧 | 视频选择及拖入类型识别包含 GIF；FPS/时长置灰；后台忽略这两个参数；Pillow 解码透明与合成帧；每次新建输出目录避免混入旧帧 |
| GIF 时序 | gif-timing.json 保存原始毫秒时长与循环元信息；扫描时核对文件列表；默认按原始节奏播放，可取消后手动调 FPS；缺失或零时长按 100ms 预览，清单保留原值 |
| 放大滚轮 | 非被动 wheel 监听阻止默认滚动；放大时锁定页面滚动，退出时恢复；保留原有缩放步长、范围及拖动效果 |
| 可选背景 | 默认不勾选“使用主预览背景”；勾选后与主预览共享棋盘、黑、白、灰、自定义图选项；取消后还原原有暗色效果；变更不重置缩放、位置、播放 |
| 区间循环 | 起止帧使用 1 起算且含两端；支持单帧范围、越界限制、恢复全帧；换素材关闭范围并重置；异步加载完成后再排下一帧，避免过期读取覆盖新帧 |
| 小窗口 | 播放控件自动换行；修正预览标签宽度不足造成的文字重叠 |

GIF 解码采用现有 Pillow 的 seek/convert 能力，参考 [Pillow GIF 文档](https://pillow.readthedocs.io/en/stable/handbook/image-file-formats.html#gif)。不增加依赖或模型。

## 其他已知情况（沿用）

- 启动入口 `src/main.tsx` 原有 `window.ipcRenderer.on` 调用，与 preload 仅暴露 cutoutAPI 不一致，会产生一条启动控制台异常。本轮预览交互可正常完成，测试单独列为 knownBaselineErrors，未新增其他页面异常。
- GIF 循环元信息保留，但查看器依照用户要求持续循环全帧或选定区间，不按源文件有限循环次数自动停止。
- 本轮未运行完整 build-internal.ps1，未修改已有分发压缩包；核对时历史 zip 已不在 release 顶层，当前是绿色目录和“视频转序列帧+智能去背景工具.rar”（509,245,823 bytes，修改时间 2026-08-07）。新 GIF 解码脚本的最终打包与干净电脑端到端验收仍待进行。
- 尚未验证超大 GIF/长序列性能、所有输入视频编码、真实用户素材及完整去背景回归，不据此宣称质量或性能达标。
