# Sequence Cutout Studio 快速使用说明

适用版本：0.4.0-internal.1

## 这个软件能帮你做什么

Sequence Cutout Studio 可以把视频或 PNG 序列帧批量处理成透明 PNG 序列。

它适合用来处理：

```text
角色动作素材
技能特效素材
简单背景前的人物或物体
需要批量去背景并导出透明 PNG 的序列帧
```

它能省掉的工作：

```text
不用手动逐帧切视频
不用逐张手动去背景
可以先测一帧再批量处理
可以在黑底、白底、灰底、棋盘格下快速检查边缘
可以自动提示可能需要复核的问题帧
可以直接导出命名好的透明 PNG 序列
```

## 适合什么素材

推荐先用这类素材测试：

```text
主体清楚
背景比较简单
主体和背景颜色差异明显
动作不要太模糊
不包含大量半透明、毛发、烟雾、玻璃
```

暂时不建议用来承诺稳定处理：

```text
毛发很多的角色
透明布料、玻璃、烟雾
主体和背景颜色很接近
复杂光效、魔法发光、强运动模糊
非常复杂的室内或街景背景
```

这些素材不是完全不能用，但需要人工仔细检查结果。

## 怎么启动

1. 解压 zip。
2. 打开解压后的文件夹。
3. 双击最外层的 `SequenceCutoutStudio-Internal.exe`。
4. 等启动画面结束，进入主界面。
5. 看到左侧环境自检通过后再开始处理。

不要直接打开 `app` 文件夹里的程序。

## 最短使用流程

```text
1. 选择视频或 PNG 序列帧文件夹
2. 如果是视频，先切成序列帧
3. 先做一次单帧测试
4. 看 Raw 和 Soft 效果
5. 效果可以，再批量处理
6. 看质量验收提示
7. 有疑似问题帧就点进去复核
8. 导出透明 PNG 序列
```

记住一句话：

```text
先单帧测试，再批量处理，最后导出。
```

## GIF / WebP 与局部查看

- 通过“选择视频”打开 GIF 或 WebP，也可以直接拖入。FPS 和时长会置灰，点击“切成序列帧”直接完整拆出 PNG；静态 WebP 输出一张 PNG。
- 拆帧保留素材本身的透明和半透明效果，不会自动去掉已有背景。
- 拆帧后默认按“原始节奏”播放；取消勾选后可以调整播放 FPS。保留同目录的 `gif-timing.json` 或 `webp-timing.json`，下次打开序列时才能恢复原始节奏。
- 勾选“区间循环”，填写起始帧和结束帧，即可反复播放这段动作。取消勾选恢复全帧播放。
- 双击预览进入放大窗口。滚轮缩放、拖动查看；需要检查背景时勾选“使用主预览背景”，通过旁边的下拉框切换背景或选择背景图片。取消勾选恢复原有放大效果，缩放和位置保留。

## Raw 和 Soft 是什么

```text
Raw：自动去背景后的初步结果。
Soft：修边后的结果，通常更适合导出和使用。
```

如果 Raw 阶段主体已经被扣掉，Soft 一般也救不回来。这种素材需要换图、换背景或人工处理。

## 怎么检查结果

建议这样看：

```text
黑底：检查白边和浅色残留
白底：检查黑边和深色残留
灰底：检查普通边缘是否自然
棋盘格：检查透明区域是否完整
播放预览：检查动画是否闪烁
```

质量验收提示“疑似问题帧”时，不代表整批都失败，只是提醒这些帧值得人工看一下。

## 导出结果在哪里

批量处理完成后，点击导出透明 PNG 序列。

导出后会得到：

```text
一组透明 PNG
manifest.json 清单
```

示例：

```text
attack_0001.png
attack_0002.png
attack_0003.png
```

这些 PNG 可以继续放进游戏引擎、动画工具或后续打包流程。

## 遇到问题怎么反馈

请尽量提供：

```text
软件版本
Windows 版本
素材类型：视频 / PNG 序列帧
素材帧数或视频时长
操作到哪一步失败
软件里的处理日志
问题帧截图
如果可以，提供一小段可公开测试素材
```

不要直接发送公司敏感素材。可以裁剪、脱敏，或用类似素材复现问题。
