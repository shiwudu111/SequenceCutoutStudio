# Sequence Cutout Studio 演示物料脚本

适用版本：0.4.0-internal.1

## 演示目标

让用户在 1-2 分钟内明白：

```text
这个软件是做序列帧透明化的。
它能从视频或 PNG 序列帧开始处理。
它可以先测一帧，再批量处理。
它能帮助检查边缘和问题帧。
它最终导出透明 PNG 序列。
```

不要把演示重点放在技术实现、模型、Python、onnxruntime 或绿色包结构上。

## 推荐演示素材

优先使用：

```text
简单背景角色动作
绿色背景或纯色背景素材
主体和背景区分明显的技能或物体素材
```

不建议作为第一条演示：

```text
低对比素材
大量毛发素材
透明布料素材
复杂光效素材
复杂室外或室内背景
```

这些可以放在“当前边界”里讲，不要放在第一屏证明效果。

## 1 分钟演示流程

### 画面 1：打开软件

操作：

```text
双击 SequenceCutoutStudio-Internal.exe
等待进入主界面
显示环境自检通过
```

讲解词：

```text
这是一个本地运行的序列帧自动去背景工具，不需要上传素材。打开后先确认环境自检通过。
```

### 画面 2：导入素材

操作：

```text
选择一个视频，或选择一个 PNG 序列帧文件夹
如果是视频，点击切序列帧
```

讲解词：

```text
可以直接导入视频，也可以导入已经切好的 PNG 序列帧。视频可以先在软件里切成序列帧。
```

### 画面 3：单帧测试

操作：

```text
点击单帧测试
展示 Raw 和 Soft 结果
切换黑底、白底、灰底或棋盘格背景
```

讲解词：

```text
正式批量处理前，先测一帧。Raw 是初步去背景结果，Soft 是修边后的结果。通过不同背景可以快速检查边缘。
```

### 画面 4：批量处理

操作：

```text
点击批量处理
等待处理完成
展示处理完成后的预览
```

讲解词：

```text
确认单帧效果可以后，再批量处理整段序列。这样可以减少一上来就跑完整批量的试错成本。
```

### 画面 5：质量验收

操作：

```text
打开质量验收区域
展示输出数量和疑似问题帧
点击一个疑似问题帧跳转预览
```

讲解词：

```text
处理完成后，软件会帮忙提示可能需要复核的帧。它不是替代人工验收，而是减少逐帧翻查的时间。
```

### 画面 6：导出透明 PNG

操作：

```text
设置导出命名
点击导出透明 PNG 序列
打开导出文件夹
展示 PNG 文件和 manifest.json
```

讲解词：

```text
最后可以导出一组命名好的透明 PNG，方便继续放进游戏引擎、动画工具或后续打包流程。
```

## 截图清单

至少准备 6 张图：

```text
01_启动后的主界面.png
02_导入素材或切帧完成.png
03_单帧测试_Raw_Soft_对比.png
04_黑白灰或棋盘格检查边缘.png
05_质量验收提示问题帧.png
06_导出的透明PNG序列.png
```

截图注意：

```text
不要出现开发路径
不要出现报错或乱码
不要用最难素材当正向案例
导出目录里文件名要清楚
质量验收截图可以显示疑似问题帧，但不要让用户误解为自动修复
```

## 可直接发用户的短文案

短版：

```text
Sequence Cutout Studio 是一个本地运行的序列帧透明化工具。它可以把视频或 PNG 序列帧处理成透明 PNG 序列，支持单帧测试、批量处理、Raw / Soft 预览、边缘检查、问题帧提示和透明 PNG 导出。
```

更口语一点：

```text
如果你有一段角色动作、技能特效或简单背景素材，想快速得到透明 PNG 序列，可以先用这个工具测一帧，看效果可以后再批量处理。它会帮你切帧、自动去背景、修边、提示可能有问题的帧，并导出命名好的透明 PNG。
```

边界说明：

```text
当前版本更适合主体清楚、背景简单、主体和背景区分明显的素材。毛发、半透明、复杂光效、低对比和复杂背景仍然需要人工检查。
```
