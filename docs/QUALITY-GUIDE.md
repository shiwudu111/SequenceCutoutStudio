# Sequence Cutout Studio 素材质量指南

适用版本：0.4.0-internal.1

---

## 1. 适合当前版本的素材

当前版本更适合：

```text
主体清楚
背景相对简单
主体和背景颜色差异明显
主体大部分是不透明材质
动作变化不剧烈
边缘没有大量毛发或透明层
```

推荐优先用于：

```text
绿幕 / 蓝幕 / 纯色背景角色
简单墙面、桌面、地面背景
轮廓清楚的游戏角色或道具
背景和主体分离明显的动画序列
```

---

## 2. 需要谨慎使用的素材

以下素材可以尝试，但需要人工检查：

```text
复杂室内背景
复杂树林或街景
快速运动
有轻微运动模糊
裙摆、披风、尖角等细长边缘
普通发光效果
```

这些素材可能出现局部闪烁、边缘残留或少量误删，需要通过质量验收和预览检查确认。

---

## 3. 当前不建议作为宣传重点的素材

当前版本不建议把下面素材作为“稳定能力”宣传：

```text
低对比：白衣白墙、黑发黑底、灰色角色灰底
毛发细节：大量头发、绒毛、羽毛
半透明材质：透明布料、玻璃、烟雾
复杂发光：大面积魔法光效、透明光带
复杂背景：树林、街景、杂物很多的室内场景
强运动：快速旋转、强模糊、严重遮挡
```

原因：这些问题多数发生在 Raw 自动去背景阶段。如果 Raw 已经把主体误删，Soft 修边不能可靠补回。

---

## 4. 质量等级建议

正式上线宣传和演示建议优先使用 A / A- 级素材。

| 等级 | 建议用途 | 判断标准 |
| --- | --- | --- |
| A / A- | 宣传、演示、正式样例 | 主体完整，背景干净，帧间稳定 |
| B / B- | 内部演示、谨慎交付 | 整体可用，但需要人工检查局部 |
| C / C- | 问题样例、能力边界说明 | 需要手工修图或更换方案 |
| D / D- | 不建议当前版本承诺 | 当前流程不适合稳定处理 |

当前测试中更适合宣传的方向：

```text
绿色背景角色
简单背景角色
遮挡旋转但轮廓清楚的序列
```

不建议宣传为稳定能力的方向：

```text
低对比角色
毛发测试
透明布料
半透明发光法术
复杂树林背景
```

---

## 5. 如何人工验收

每组素材至少检查：

```text
首帧
中间帧
末帧
动作幅度最大的几帧
质量验收提示的疑似问题帧
```

重点看：

```text
主体是否完整
身体、衣摆、头发、武器是否被误删
背景是否残留
黑底下是否有白边
白底下是否有黑边
灰底下边缘是否自然
播放时是否闪烁
导出 PNG 数量是否正确
```

---

## 6. 质量验收的正确理解

质量验收会辅助提示：

```text
数量是否一致
是否有疑似问题帧
哪些帧值得检查
```

它不能保证：

```text
自动识别所有视觉问题
自动修复误删主体
自动判断素材是否最终可商用
```

质量验收通过，表示没有发现明显异常，不等于不需要人工抽查。  
质量验收发现疑似问题，表示这些帧值得优先检查，不等于整批一定不可用。

---

## 7. 发布前宣传边界

推荐表达：

```text
适合主体明确、背景相对简单的序列帧去背景。
支持质量验收，能提示疑似问题帧。
适合游戏美术批量处理透明 PNG 序列。
```

避免表达：

```text
任何背景都能完美抠图。
毛发、半透明、复杂光效无需人工检查。
一键生成可直接进引擎的所有格式。
不需要美术复核。
```
