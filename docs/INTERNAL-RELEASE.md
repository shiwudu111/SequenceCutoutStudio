## 1. 这是什么

Sequence Cutout Studio 是一个本地桌面工具，用来把视频或 PNG 序列帧处理成透明 PNG 序列。

主要流程：

```text
导入视频 / PNG 序列帧
视频切帧 / 扫描序列帧
单帧测试
批量自动去背景
修边
预览检查
导出透明 PNG 序列
```

当前版本优先保证绿色包稳定、本地可运行、主流程完整。账号、云端处理、自动更新、Sprite Sheet、TexturePacker JSON、Cocos plist 等高级能力不在本版本范围内。

## 2. 启动方式

1. 解压 zip 到普通本地目录，例如 `D:\Tools\SequenceCutoutStudio-Internal`。
2. 打开解压后的文件夹。
3. 双击顶层的 `SequenceCutoutStudio-Internal.exe`。
4. 等待启动画面结束后进入主界面。
5. 左侧环境自检显示通过后开始使用。

不要直接运行 `app\SequenceCutoutStudio.exe`。顶层启动器负责显示启动画面并启动主程序。

首次启动可能需要 30-60 秒，请不要连续重复双击。

## 3. 推荐验收流程

正式发布前建议按下面顺序复核一次：

```text
1. 启动软件
2. 等待环境自检通过
3. 选择一个视频或 PNG 序列帧文件夹
4. 如果是视频，先切成序列帧
5. 运行单帧测试
6. 查看 Raw / Soft 预览
7. 运行批量处理
8. 查看质量验收结果
9. 点击疑似问题帧进行复核
10. 导出透明 PNG 序列
11. 打开导出目录检查 PNG 数量和命名
```

重点观察：

```text
软件是否能启动
环境自检是否通过
视频切帧是否成功
单帧测试是否成功
批量处理是否完成
质量验收是否能提示疑似问题
导出 PNG 序列是否生成正确文件
失败时日志是否能看懂
```

## 4. 当前支持能力

当前版本支持：

```text
MP4 / MOV / WEBM / MKV 视频导入
PNG 序列帧文件夹导入
视频切帧
单帧测试
批量自动去背景
Raw 初步结果预览
Soft 修边结果预览
黑底 / 白底 / 灰底 / 棋盘格 / 自定义背景预览
质量验收与疑似问题帧提示
按规则导出透明 PNG 序列
导出文件重命名
导出 manifest.json 清单
```

导出命名规则支持：

```text
导出前缀
起始编号
补零位数
```

示例：

```text
frame_0001.png
frame_0002.png
frame_0003.png
```

## 5. 已知限制

当前版本不承诺稳定处理以下素材：

```text
主体和背景颜色非常接近的低对比素材
大量毛发、绒毛、羽毛等细碎边缘
透明布料、玻璃、烟雾等半透明材质
大面积发光、魔法光效、复杂透明特效
复杂树林、街景、杂物很多的室内背景
强运动模糊、快速旋转、严重遮挡的序列
```

这些素材可能出现：

```text
主体部分被当作背景扣掉
边缘残留背景
黑边或白边
发光区域保留不完整
帧间闪烁
质量验收提示疑似问题帧
```

质量验收不是自动修图功能。它的作用是帮助用户更快发现需要人工检查的帧。
