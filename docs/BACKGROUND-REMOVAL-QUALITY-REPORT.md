# Phase 6A 去背景质量测试报告

版本：0.4.0-internal.1  
日期：2026-06-04  
阶段目标：先评估当前去背景质量，再决定后续优化方向。  

---

## 1. 本阶段边界

Phase 6A 只做质量评估，不直接改算法、不改参数、不改 postprocess、不改 rembg / portable Python / launcher 链路。

本报告用于回答：

```text
1. 当前去背景在不同背景下表现如何
2. 哪些场景已经适合内测使用
3. 哪些场景需要继续优化
4. 问题主要来自 Raw 自动去背景，还是 Soft 修边
5. 下一阶段应该优先优化哪一类问题
```

---

## 2. 评级规则

每个样本按最终 Soft 结果评级，同时记录 Raw 与 Soft 的差异。

```text
A：可直接用于游戏透明序列素材
B：轻微修边后可用，适合内测
C：需要手工补图或换参数，暂不适合批量交付
D：当前流程不适合，应该进入后续专项优化
```

每个样本至少记录：

```text
素材类型
背景类型
主体类型
帧数
Raw 是否漏抠
Raw 是否误删主体
Soft 是否改善边缘
Soft 是否引入发黑 / 发白 / 染色
是否有帧间闪烁
最终评级
备注
```

## 3. 测试集分类

Phase 6A 后续应补齐这些背景类型。当前不能只用一个 sample_video 下结论。

| 分类 | 测试目的 | 建议样本 |
| --- | --- | --- |
| 纯色背景 | 验证基础可用性 | 白底、黑底、绿幕、蓝幕、灰底 |
| 简单背景 | 验证常见素材环境 | 墙面、桌面、地面、简单渐变 |
| 复杂背景 | 验证误抠风险 | 树林、街景、室内杂物、游戏截图 |
| 低对比背景 | 验证主体与背景接近时的稳定性 | 白衣白墙、黑发黑底、灰色角色灰底 |
| 细节边缘 | 验证边缘保留 | 头发、毛绒、羽毛、尖角、裙摆 |
| 半透明 / 发光 | 验证 alpha 与颜色污染 | 光效、玻璃、烟雾、半透明布料 |
| 动画序列 | 验证帧间一致性 | 快速运动、运动模糊、遮挡、旋转 |

最低可用测试集建议：

```text
每类至少 2 个样本
每个序列至少 12 帧
优先使用真实游戏美术 / 外包素材，而不是只用演示视频
```

## 5. 人工视觉检查表

每个样本需要至少人工检查首帧、中间帧、末帧，以及运动幅度最大的几帧。

| 检查项 | 判断 |
| --- | --- |
| 主体是否完整 | 重点看头发、手指、尾巴、武器尖角、衣摆 |
| 背景是否残留 | 重点看主体周围一圈、透明洞、阴影 |
| 边缘是否发黑 | 常见于深色背景或预乘颜色污染 |
| 边缘是否发白 | 常见于白底或浅色背景 |
| 颜色是否被背景染色 | 重点看半透明区域和毛边 |
| 细节是否被抹掉 | 头发、毛绒、羽毛、烟雾、发光边缘 |
| 帧间是否闪烁 | 连续播放 Raw / Soft，观察边缘跳动 |
| 是否适合进游戏 | 放到深色、浅色、棋盘背景下分别看 |

## 6. 优化方向判断规则

后续不要一看到效果问题就直接改后处理。先按下面规则归因：

```text
Raw 已经漏掉主体：
优先考虑输入质量、模型能力、单帧预处理、素材约束。

Raw 主体完整但边缘脏：
优先考虑 Soft 修边、颜色修正、alpha 边缘处理。

Raw / Soft 单帧好，但连续播放闪：
优先考虑序列一致性、参数锁定、帧间稳定策略。

纯色背景好，复杂背景差：
优先考虑使用说明、测试样本分级、后续高级模式。

低对比背景差：
优先考虑素材前处理、模型选择、人工辅助输入，而不是只调 shrink。

半透明 / 发光差：
单独列为高级素材，不放进短期默认流程承诺。
```
